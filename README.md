# 🎨 Design

Welcome to the NeoNephos Design repository.

This repository is the central place for all design-related work within the NeoNephos Foundation.

---

## 🎯 Purpose

The goal of this repository is to:

- Collaborate openly on new ideas
- Collect all current design tasks in one place for a better overview
- Document design decisions and their rationale

---

## 🤝 Contributing

Everyone is welcome to contribute!

Whether you have an idea, a sketch, a concept, or simply some feedback, we'd love to hear from you. Feel free to open an issue or join an existing discussion.
